# FocusFlow Dashboard

A modern productivity dashboard built with React, TypeScript, Vite, Tailwind CSS, and Supabase Authentication. This project demonstrates a clean frontend architecture with authentication, user management, and feedback collection features.

> ⚠️ This repository is a learning and portfolio project. It is under active development and is not intended for production use.

---

## Features

- Email & Password Authentication
- Google OAuth Login
- User Registration
- Protected Dashboard
- Feedback Submission
- Responsive UI
- Modern Component Architecture
- Backend API Integration
- MongoDB Feedback Storage

